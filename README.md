# תדביקלי — Windows Cloud-Only releases

מאגר ציבורי זה מכיל קובצי הפצה, manifest חתום והוראות התקנה עבור מהדורת
Windows Cloud-Only של תדביקלי. קוד המקור של האפליקציה אינו מפורסם כאן.

הוראות למשתמש נמצאות ב־`FRIEND-BETA-INSTRUCTIONS.md`. נכסי ההתקנה נמצאים
ב־GitHub Releases. עדכונים באפליקציה נקראים מ־`production/manifest.json`.

אין לפרסם במאגר מפתחות פרטיים, credentials, מסדי נתוני משתמש, logs או אודיו.
