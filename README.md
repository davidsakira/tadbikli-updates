החבילה מתאימה ל־Windows 10/11 x64 במחשבי Intel ו־AMD. נדרשים אינטרנט,
מיקרופון ומפתח Soniox אישי. מפתח OpenAI אופציונלי. אין צורך ב־.NET,
Python, CUDA או מודל מקומי.

מאגר ציבורי זה מכיל קובצי הפצה, manifest חתום והוראות בלבד. קוד המקור של
האפליקציה אינו מפורסם כאן. אין לפרסם במאגר מפתחות פרטיים, credentials,
מסדי נתוני משתמש, logs או אודיו.
