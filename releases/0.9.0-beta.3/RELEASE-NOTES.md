# תדביקלי 0.9.0-beta.3 — Windows Cloud-Only Friend Beta

גרסת בטא ראשונה להורדה לחברים עבור Windows 10/11 x64 במחשבי Intel ו־AMD.

## כלול

- תמלול Soniox בזמן אמת והדבקה מהירה.
- עיבוד OpenAI אופציונלי, פרופילים ועריכת טקסט מסומן.
- פקודות, Widget, היסטוריה וסטטיסטיקות.
- Game Mode עם Restore Modes מפורשים.
- כיבוי מתוזמן, שחזור, Clipboard בטוח ועדכונים מתוך האפליקציה.
- סביבת ‎.NET עצמאית — אין צורך להתקין runtime נוסף.

## לא כלול

- Whisper מקומי, Local AI, מודלים מקומיים, Python, ‏CUDA או תלות ב־NVIDIA.

## חשוב

- נדרש חיבור לאינטרנט ומפתח Soniox אישי.
- מפתח OpenAI נדרש רק למי שבוחר עיבוד AI.
- זוהי גרסת בטא ללא חתימת Authenticode; Windows SmartScreen עשוי להציג
  `Unknown publisher`. יש לבחור `More info` ואז `Run anyway`.

## התקנה קצרה

1. הורד את `TadbikliSetup-0.9.0-beta.3.exe` מהנכסים שלמטה.
2. אם SmartScreen מופיע, בחר `More info` ואז `Run anyway`.
3. השלם את מסך ההיכרות, בחר מיקרופון ומקש הפעלה.
4. בהגדרות, שמור מפתח Soniox אישי. מפתח OpenAI נדרש רק לעיבוד AI.

## עדכונים ומגבלות

- תדביקלי בודקת עדכונים בשקט. כשיש גרסה חדשה מופיע `עדכון חדש זמין`,
  וההורדה וההתקנה מתבצעות מתוך אזור העדכונים בהגדרות.
- זוהי Friend Beta ל־Windows x64. בדיקת AMD הפיזית הסופית תתבצע במחשב החבר.
- אין בגרסה זו תמלול מקומי או עיבוד מקומי; ללא אינטרנט התמלול אינו זמין.
